# Briza Maldonado — sitio web

Sitio de Briza Maldonado, tatuadora en Palermo, Buenos Aires. Hecho con Next.js (exportación estática).

- **En línea:** https://briza-maldonado.vercel.app
- **Publicación:** Vercel publica automáticamente cada cambio que entra a `main`.
- **Desarrollo local:** `npm install` y después `npm run dev`.
- **Asistente de turnos:** ver `agent/README.md`.
