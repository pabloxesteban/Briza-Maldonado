# Short-form retention

Simular a un usuario scrolleando con el pulgar listo:
| Ventana | Pregunta | Falla típica |
|---|---|---|
| 0–1 s | ¿Frena el scroll? (contraste visual, texto que promete algo, rostro/figura, movimiento) | intro lenta, logo, saludo |
| 1–3 s | ¿Abre curiosidad? | se entiende todo de una |
| 3–5 s | ¿Entiendo el juego/contexto? | confusión total |
| mitad | ¿Hay escalada o nueva info cada 2–4 s? | meseta |
| final | ¿Payoff/punchline? | termina flojo |
| después | ¿Loop, share, comentario? | final cerrado sin invitación |

Herramientas: drop/beat visible, texto que cambia cada 2–3 s, elementos que se acumulan, loop (último frame encaja con el primero).
Entregar: tabla por segundo con riesgo (bajo/medio/alto) + fix concreto.
